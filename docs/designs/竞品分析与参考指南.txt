1. LaVague (lavague-ai/LaVague)
================================================================================

GitHub: https://github.com/lavague-ai/LaVague
定位:   Large Action Model 框架 - Web Agent 开发框架
Stars:  5.6k+
语言:   Python

1.1 核心架构
───────────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                           LaVague Agent                             │
    ├─────────────────────────────────────────────────────────────────────┤
    │                                                                     │
    │  ┌─────────────────────┐     ┌─────────────────────────────────┐   │
    │  │    World Model      │ ──► │      Action Engine              │   │
    │  │                     │     │                                 │   │
    │  │ • 理解目标          │     │ • 编译指令为代码                │   │
    │  │ • 分析当前页面状态  │     │ • 执行 Selenium/Playwright    │   │
    │  │ • 输出操作指令      │     │ • 实际与网页交互               │   │
    │  └─────────────────────┘     └─────────────────────────────────┘   │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘

    重明映射:
    ├── World Model    → 神经设计层 + 意图规划
    └── Action Engine  → 右瞳引擎 (执行层)

1.2 核心功能
───────────────────────────────────────────────────────────────────────────────

    ┌────────────────────────┬────────────────────────────────────────────┐
    │ 功能                   │ 描述                                       │
    ├────────────────────────┼────────────────────────────────────────────┤
    │ Built-in Contexts      │ 预设配置，类似重明的"测试上下文"          │
    │ LaVague QA             │ Gherkin → 自动化测试，类似 TC-IR 转换     │
    │ Test Runner            │ 测试 + 基准性能评估                        │
    │ Token Counter          │ Token 用量估算，对应重明的成本监控        │
    │ Gradio Interface       │ 交互式 UI，对应重明的前端层               │
    │ Chrome Extension       │ 浏览器扩展驱动                            │
    └────────────────────────┴────────────────────────────────────────────┘

1.3 建议抄作业
───────────────────────────────────────────────────────────────────────────────

    高优先级:
    ├── lavague/core/world_model.py     → DOM → Markdown 摘要算法
    ├── lavague/core/html_extractor.py  → HTML 压缩逻辑 (几万行 → 几百 Token)
    └── Ollama 本地模型集成方式

    中优先级:
    ├── Token 计数器实现
    └── Gherkin → 测试的转换逻辑

3. Mind2Web (OSU-NLP-Group/Mind2Web)
================================================================================

GitHub: https://github.com/OSU-NLP-Group/Mind2Web
定位:   Web Agent 数据集 + Benchmark
发表:   NeurIPS 2023 Spotlight
语言:   Python

3.1 数据集概况
───────────────────────────────────────────────────────────────────────────────

    ┌────────────────────────────────────────────────────────────────────────┐
    │                          Mind2Web Dataset                              │
    ├────────────────────────────────────────────────────────────────────────┤
    │  • 2,000+ 开放式任务                                                   │
    │  • 137 真实网站                                                        │
    │  • 31 领域覆盖                                                         │
    │  • 3 测试集: test_task, test_website, test_domain                     │
    └────────────────────────────────────────────────────────────────────────┘

3.2 关键数据结构 (DOM 清洗标准)
───────────────────────────────────────────────────────────────────────────────

    每个 Action 包含:

    {
      "action_uid": "唯一动作ID",
      "raw_html": "原始 HTML (完整页面)",
      "cleaned_html": "清洗后 HTML (压缩版)",
      
      "operation": {
        "op": "CLICK | TYPE | SELECT",
        "value": "可选值 (输入文本/选择选项)"
      },
      
      "pos_candidates": [  // 正样本元素
        {
          "tag": "button",
          "is_original_target": true,
          "is_top_level_target": true,
          "backend_node_id": "唯一元素ID",
          "attributes": "{\"class\": \"btn\", \"id\": \"submit\"}"
        }
      ],
      
      "neg_candidates": [  // 负样本元素 (其他候选)
        ...
      ]
    }

3.3 对重明的参考价值
───────────────────────────────────────────────────────────────────────────────

    ┌────────────────────────┬────────────────────────────────────────────┐
    │ Mind2Web 概念           │ 重明对应                                   │
    ├────────────────────────┼────────────────────────────────────────────┤
    │ raw_html               │ 原始 DOM 快照                              │
    │ cleaned_html           │ DOM 剪枝后的精简 HTML                      │
    │ pos_candidates         │ 目标元素候选集                             │
    │ neg_candidates         │ 相似元素排除集                             │
    │ operation.op           │ AUI-IR 的 action 字段                      │
    │ backend_node_id        │ 元素唯一标识                               │
    └────────────────────────┴────────────────────────────────────────────┘

3.4 建议抄作业
───────────────────────────────────────────────────────────────────────────────

    高优先级:
    ├── cleaned_html 生成规则    → DomTreeSimplifier 实现参考
    ├── pos_candidates 构建逻辑  → 元素匹配置信度计算
    └── is_top_level_target 算法 → 嵌套元素判断

    中优先级:
    ├── 用 Mind2Web 作为重明的 Benchmark 数据集
    └── 参考 Multimodal-Mind2Web (HTML + 截图配对)

================================================================================

GitHub: https://github.com/microsoft/UFO
定位:   Windows 桌面自动化 Agent → 多设备编排框架
Stars:  23k+
语言:   Python

4.1 版本演进
───────────────────────────────────────────────────────────────────────────────

    2024.02 ──► 2025.04 ──► 2025.11
       │           │           │
       ▼           ▼           ▼
      UFO        UFO²        UFO³
   (初版)    (Desktop    (Galaxy
             AgentOS)    多设备编排)

4.2 UFO³ Galaxy 架构 (2025.11 最新)
───────────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                          UFO³ Galaxy                                │
    ├─────────────────────────────────────────────────────────────────────┤
    │                                                                     │
    │                    User Request                                     │
    │                         │                                           │
    │                         ▼                                           │
    │               ConstellationAgent                                    │
    │                         │                                           │
    │                         ▼                                           │
    │                    [Task DAG]                                       │
    │                   /    |    \                                       │
    │                  ▼     ▼     ▼                                      │
    │              Task1  Task2  Task3                                    │
    │              (Win)  (Linux)(Mac)                                    │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘

    五大设计原则:

    1. 🌟 Declarative Decomposition into Dynamic DAG
       - 请求分解为结构化 DAG (TaskStars + 依赖关系)
       - 自动调度 + 运行时重写

    2. 🔄 Continuous Result-Driven Graph Evolution
       - 活的星座图，根据执行反馈自适应调整
       - 受控重写 + 动态调整

    3. ⚡ Heterogeneous, Asynchronous & Safe Orchestration
       - 基于能力的设备匹配
       - 异步执行 + 安全锁 + 形式化验证

    4. 🔌 Unified Agent Interaction Protocol (AIP)
       - WebSocket 安全协调层
       - 容错 + 自动重连

    5. 🛠️ Template-Driven MCP-Empowered Device Agents
       - 轻量级工具包快速开发 Agent
       - MCP 集成增强

4.3 对重明的参考价值
───────────────────────────────────────────────────────────────────────────────

    ┌────────────────────────┬────────────────────────────────────────────┐
    │ UFO 概念               │ 重明对应                                   │
    ├────────────────────────┼────────────────────────────────────────────┤
    │ HostAgent              │ 分发器 (Dispatcher)                        │
    │ AppAgent               │ 右瞳/左瞳引擎                              │
    │ ConstellationAgent     │ 并行执行调度器                             │
    │ Task DAG               │ AUI-IR → DAG 调度图                        │
    │ AIP (Agent Interaction)│ 引擎间通信协议                             │
    │ Human-in-the-loop      │ 人工确认界面 (Confirm Gate)               │
    │ Windows Step Recorder  │ 从人类演示中学习                           │
    └────────────────────────┴────────────────────────────────────────────┘

4.4 建议抄作业
───────────────────────────────────────────────────────────────────────────────

5. SeeAct (OSU-NLP-Group/SeeAct)
================================================================================

GitHub: https://github.com/OSU-NLP-Group/SeeAct
定位:   GPT-4V 驱动的通用 Web Agent
发表:   ICML 2024
语言:   Python

5.1 核心流程
───────────────────────────────────────────────────────────────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                           SeeAct Flow                               │
    ├─────────────────────────────────────────────────────────────────────┤
    │                                                                     │
    │  浏览器 ──► Playwright ──► SeeAct Tool ──► LMM (GPT-4V)            │
    │     │                                          │                    │
    │     │                                          ▼                    │
    │     │                                   Action Generation           │
    │     │                                   (生成文本计划)              │
    │     │                                          │                    │
    │     │                                          ▼                    │
    │     │                                   Action Grounding            │
    │     │                                   (定位具体元素)              │
    │     │                                          │                    │
    │     ◄────────────────────────────────────────────                   │
    │                      执行                                           │
    └─────────────────────────────────────────────────────────────────────┘

5.2 Visual Grounding 策略
───────────────────────────────────────────────────────────────────────────────

    支持的 Grounding 模式:

    ┌────────────────────────┬────────────────────────────────────────────┐
    │ 模式                   │ 描述                                       │
    ├────────────────────────┼────────────────────────────────────────────┤
    │ text_choice            │ 纯文本选择                                 │
    │ text_choice_som        │ 文本选择 + Set-of-Mark 标注               │
    └────────────────────────┴────────────────────────────────────────────┘

    关键发现:
    ├── ⚠️ Set-of-Mark 在复杂页面会产生 GPT-4V 幻觉
    ├── ✅ 最佳策略: HTML 结构 + 视觉渲染 结合
    └── Oracle Grounding 下可完成 50%+ 任务

5.3 对重明的参考价值
───────────────────────────────────────────────────────────────────────────────

    ┌────────────────────────┬────────────────────────────────────────────┐
    │ SeeAct 概念            │ 重明对应                                   │

    │ Action Generation      │ 意图规划 (Intent → Plan)                  │
    │ Action Grounding       │ 视觉定位 (Plan → Element)                 │
    │ text_choice_som        │ OmniParser SoM 标注                       │
    │ Playwright Interface   │ 右瞳引擎 Playwright 集成                  │
    └────────────────────────┴────────────────────────────────────────────┘
