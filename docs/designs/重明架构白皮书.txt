1.1 项目愿景
───────────────────────────────────────────────────────────────────────────────

重明 (ChongMing) 是一个基于 AI Agent 的全栈自动化质量工程平台。

不同于传统自动化工具（仅执行脚本）或早期 AI 测试工具（仅做探索），
重明的核心理念是 "资产生产工厂"：

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │    利用 AI 的概率性智能探索软件                                      │
    │           ↓                                                         │
    │    将探索结果坍缩为确定性的工程资产（代码）                           │
    │           ↓                                                         │
    │    赋予资产自愈重生的能力                                            │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘

3.1 三态定义
───────────────────────────────────────────────────────────────────────────────

测试任务在三种物理形态间转化，如同水的三态变化：

    ┌─────────────────────────────────────────────────────────────────────────┐
    │                                                                         │
    │   ╔═══════════════╗     凝结     ╔═══════════════╗     升华            │
    │   ║   液态        ║ ──────────→ ║   固态        ║ ──────────→         │
    │   ║   LIQUID      ║             ║   SOLID       ║                      │
    │   ║               ║             ║               ║     ╔═══════════════╗│
    │   ║  AI 探索执行  ║             ║  脚本固化执行 ║     ║   气态        ║│
    │   ║  高智能消耗   ║             ║  零智能消耗   ║     ║   GASEOUS     ║│
    │   ║  概率性输出   ║             ║  确定性输出   ║     ║               ║│
    │   ╚═══════════════╝             ╚═══════════════╝     ║  自愈修复     ║│
    │          ▲                             │              ║  瞬时智能     ║│
    │          │                             │              ╚═══════════════╝│
    │          │            液化             ▼                     │         │
    │          └──────────────────────────────┴─────────────────────┘         │
    │                                                                         │
    └─────────────────────────────────────────────────────────────────────────┘

3.2 液态 (Liquid State) - 探索期
───────────────────────────────────────────────────────────────────────────────

    特征:
    • 高智能：调用 LLM 进行视觉理解和逻辑推理
    • 高算力消耗：OmniParser GPU 视觉识别
    • 概率性：AI 输出具有不确定性

    行为:
    • Agent 像人类一样"看屏幕"进行 UI 操作
    • Agent 像人类一样"读文档"理解 API 逻辑
    • 实时决策，边探索边执行

    产出:
    • Trace Log (执行轨迹)
    • Golden Samples (金样数据)
    • AUI-IR / API-IR (中间表示)

3.3 固态 (Solid State) - 运行期
───────────────────────────────────────────────────────────────────────────────

    特征:
    • 零智能：纯代码执行，无 LLM 调用
    • 极速：毫秒级执行速度
    • 确定性：相同输入产生相同输出

    行为:
    • 凤凰涅槃层将轨迹编译为 Python 脚本 (test_xxx.py)
    • 脚本在 CI/CD 中通过 Pytest 运行
    • 性能测试脚本通过 Locust 执行

    产出:
    • 测试报告 (Allure)
    • 回归结论
    • 性能指标

3.4 气态 (Gaseous State) - 自愈期
───────────────────────────────────────────────────────────────────────────────

    特征:
    • 瞬时智能：仅在失败时调用 AI
    • 高干预：修复选择器、更新逻辑
    • 热修补：无需人工介入

    触发条件:
    • 固态脚本执行失败
    • 元素定位器失效
    • 页面结构变化

    行为:
    • 失败时升华为液态
    • AI 分析失败原因
    • 自动修复并热更新脚本
