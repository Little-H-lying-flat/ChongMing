1.1 背景与动机
--------------
当前 AI 自动化测试存在两个核心痛点:

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │  痛点 1: 规划太慢                                                   │
    │  ═══════════════                                                    │
    │  问题: 每次操作都需要 LLM 进行意图规划，引入 2-5 秒延迟             │
    │  场景: 回归测试中执行已知路径，规划是多余的                         │
    │                                                                     │
    │  痛点 2: 定位不准                                                   │
    │  ═══════════════                                                    │
    │  问题: 密集 UI (编辑器侧边栏、复杂表格) 识别精度低                  │
    │  原因: 单次视觉识别无法区分相似元素                                 │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘

1.2 解决方案
------------
引入双模态执行机制:

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │  解决方案 1: 原子执行模式 (Atomic Execution Mode)                   │
    │  ═══════════════════════════════════════════════════                │
    │  映射自: Midscene Instant Actions (aiTap, aiInput)                  │
    │  原理: 跳过意图规划层，直接调用视觉定位层                           │
    │  收益: 消除规划不确定性，速度提升 50%+                              │
    │                                                                     │
    │  解决方案 2: 多级视觉聚焦 (Multi-Stage Visual Focus)                │
    │  ═══════════════════════════════════════════════════                │
    │  映射自: Midscene Deep Think                                        │
    │  原理: 全局 → 区域 → 元素 三级渐进式定位                            │
    │  收益: 解决密集 UI 定位难题，精度提升 30%+                          │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘

1.3 设计原则
------------
    "Fast for Known, Smart for Unknown"
    (已知路径走快速，未知场景走智能)

                    3. 原子执行模式 (Atomic Execution Mode)
================================================================================

3.1 设计理念
------------
    "Instant Actions - 即时操作，零规划延迟"

传统流程:
    用户指令 → LLM 意图解析 → 步骤规划 → 循环执行
                 ↓
            2-5s 延迟

原子流程:
    用户指令 → 直接视觉定位 → 单步执行
                 ↓
            0.5-1s 延迟

                4. 多级视觉聚焦 (Multi-Stage Visual Focus)
================================================================================

4.1 设计理念
------------
    "Deep Think - 深度思考，渐进聚焦"

传统单次识别:
    全屏截图 → OmniParser → 所有元素 → 匹配目标
                               ↓
                    密集 UI 中容易误识别

多级聚焦:
    全屏 → 识别区域 → 裁剪 → 精确定位
                ↓
        三级渐进，逐步缩小范围

4.2 三级聚焦策略

4.3 聚焦触发条件
----------------
多级聚焦模式不是默认开启，而是在以下条件触发:

┌────────────────────────┬────────────────────────────────────────────────┐
│       触发条件         │                   描述                         │
├────────────────────────┼────────────────────────────────────────────────┤
│ 元素密度高             │ OmniParser 检测到 >50 个元素在目标区域         │
│ 置信度低               │ 首次定位置信度 < 0.7                           │
│ 多个候选               │ 匹配到多个相似元素 (如 5 个 "button")          │
│ 用户指定               │ deepFocus: true 配置项                         │
│ UI 类型匹配            │ 检测到编辑器、侧边栏、表格等复杂组件           │
└────────────────────────┴────────────────────────────────────────────────┘

7.1 原子执行器
--------------
class AtomicExecutor:
    """原子操作执行器"""
    
    def __init__(
        self,
        visual_locator: VisualLocator,
        playwright_page: Page,
        deep_focus_engine: DeepFocusEngine
    ):
        self.locator = visual_locator
        self.page = playwright_page
        self.deep_focus = deep_focus_engine
    
    async def execute(self, request: AtomicActionRequest) -> ActionResult:
        """执行原子操作"""
        # 1. 截图
        screenshot = await self.page.screenshot()
        
        # 2. 定位 (根据是否启用深度聚焦)
        if request.deep_focus:
            focus_result = await self.deep_focus.locate(
                screenshot, request.target
            )
            coords = focus_result.absolute_coords
            confidence = focus_result.final_confidence
        else:
            locate_result = await self.locator.locate(
                screenshot, request.target
            )
            coords = locate_result.coords
            confidence = locate_result.confidence
        
        # 3. 执行动作
        if request.action == "tap":
            await self.page.mouse.click(coords[0], coords[1])
        elif request.action == "input":
            await self.page.mouse.click(coords[0], coords[1])
            await self.page.keyboard.type(request.value)
        elif request.action == "hover":
            await self.page.mouse.move(coords[0], coords[1])
        elif request.action == "scroll":
            await self.page.mouse.wheel(0, 200 if request.value == "down" else -200)
        
        return ActionResult(success=True, coords=coords, confidence=confidence)

7.2 深度聚焦引擎

class DeepFocusEngine:
    """多级视觉聚焦引擎"""
    
    def __init__(
        self,
        qwen_vl_client: QwenVLClient,
        omniparser: OmniParser
    ):
        self.qwen = qwen_vl_client
        self.omniparser = omniparser
    
    async def locate(
        self, 
        screenshot: bytes, 
        target: str
    ) -> DeepFocusResult:
        """三级聚焦定位"""
        
        # Stage 1: 全局区域识别
        region_prompt = f"请识别'{target}'所在的UI功能区域，返回边界框坐标 [x1,y1,x2,y2]"
        region_response = await self.qwen.analyze(screenshot, region_prompt)
        region_box = self.parse_region(region_response)
        
        # Stage 2: 区域裁剪 + 元素检测
        cropped = self.crop_image(screenshot, region_box)
        elements = await self.omniparser.detect(cropped)
        
        # Stage 3: 精确匹配
        match_prompt = f"在以下元素中找到'{target}':\n{elements}\n返回序号"
        match_response = await self.qwen.analyze(cropped, match_prompt)
        target_idx = self.parse_index(match_response)
        
        target_element = elements[target_idx]
        absolute_coords = self.to_absolute(target_element.coords, region_box)
        
        return DeepFocusResult(
            region_box=region_box,
            elements_in_region=elements,
            target_element=target_element,
            absolute_coords=absolute_coords,
            stages_executed=3
        )

7.3 模式路由器
--------------
class ModeRouter:
    """执行模式路由器"""
    
    # 原子动作关键词
    ATOMIC_ACTIONS = {"tap", "click", "input", "type", "hover", "scroll", "select"}
    
    def detect_mode(self, tc_ir: dict) -> ExecutionMode:
        """检测执行模式"""
        
        # 1. 显式指定优先
        if tc_ir.get("mode") == "atomic":
            return ExecutionMode.ATOMIC
        if tc_ir.get("mode") == "planning":
            return ExecutionMode.PLANNING
        
        # 2. 根据动作类型推断
        action = tc_ir.get("action", "").lower()
        if action in self.ATOMIC_ACTIONS:
            target = tc_ir.get("target", "")
            # 目标明确则使用原子模式
            if self.is_explicit_target(target):
                return ExecutionMode.ATOMIC
        
        # 3. 默认规划模式
        return ExecutionMode.PLANNING
    
    def is_explicit_target(self, target: str) -> bool:
        """判断目标是否明确"""
        # 模糊词汇
        FUZZY_KEYWORDS = ["某个", "一个", "任意", "相关", "类似"]
        return not any(kw in target for kw in FUZZY_KEYWORDS)
