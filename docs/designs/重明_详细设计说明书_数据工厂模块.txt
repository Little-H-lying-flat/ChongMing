1. 系统概述 (System Overview)

1.1 定义与愿景

数据工厂模块 (Data Factory) 是重明架构中负责 "造" (Generate) 和 "管" (Manage) 测试数据的核心组件。它像一个智能的数据生产车间，根据测试需求自动生成、管理、脱敏测试数据。

其核心设计哲学是 "Schema-Driven, AI-Enhanced" (模式驱动，AI 增强)：
- 模式驱动：基于数据 Schema 自动生成符合规则的测试数据
- AI 增强：利用 LLM 生成语义真实的业务数据
- 数据脱敏：保护隐私，安全使用生产数据
- 参数化驱动：支持数据驱动测试 (DDT)

1.2 核心职责
- 数据生成 (Data Generation)：基于规则/AI 生成测试数据
- 数据模板 (Data Template)：定义可复用的数据结构
- 数据脱敏 (Data Masking)：敏感数据脱敏处理
- 数据池管理 (Data Pool)：统一管理测试数据生命周期
- 数据驱动 (Data-Driven)：支持参数化测试

3.2 规则生成器

class RuleGenerator:
    def __init__(self):
        self.faker = Faker('zh_CN')
        self.type_handlers = {
            'string': self._gen_string,
            'integer': self._gen_integer,
            'number': self._gen_number,
            'boolean': self._gen_boolean,
            'date': self._gen_date,
            'datetime': self._gen_datetime,
            'email': self._gen_email,
            'phone': self._gen_phone,
            'id_card': self._gen_id_card,
            'address': self._gen_address
        }
    
    def generate(self, schema: DataSchema, count: int = 1) -> list[dict]:
        results = []
        for _ in range(count):
            record = {}
            for field in schema.fields:
                handler = self.type_handlers.get(field.type)
                if handler:
                    record[field.name] = handler(field)
                else:
                    record[field.name] = self._gen_by_pattern(field)
            results.append(record)
        return results
    
    def _gen_string(self, field: FieldSpec) -> str:
        if field.pattern:
            return exrex.getone(field.pattern)
        min_len = field.min_length or 1
        max_len = field.max_length or 20
        return self.faker.pystr(min_chars=min_len, max_chars=max_len)
    
    def _gen_email(self, field: FieldSpec) -> str:
        return self.faker.email()
    
    def _gen_phone(self, field: FieldSpec) -> str:
        return self.faker.phone_number()
    
    def _gen_id_card(self, field: FieldSpec) -> str:
        return self.faker.ssn()

4.2 模板解析器

class TemplateParser:
    def __init__(self):
        self.env = jinja2.Environment()
        self.functions = {
            'random': RandomFunctions(),
            'faker': Faker('zh_CN'),
            'now': datetime.now
        }
    
    def parse(self, template: DataTemplate, variables: dict = None) -> list[dict]:
        results = []
        
        for scenario in template.scenarios:
            base_data = template.data[scenario.template]
            
            for i in range(scenario.count):
                # 合并变量
                context = {**self.functions, **(variables or {}), 'index': i}
                
                # 渲染模板
                rendered = self._render_dict(base_data, context)
                rendered['_scenario'] = scenario.name
                results.append(rendered)
        
        return results
    
    def _render_dict(self, data: dict, context: dict) -> dict:
        result = {}
        for key, value in data.items():
            if isinstance(value, str) and '${' in value:
                result[key] = self._render_string(value, context)
            elif isinstance(value, dict):
                result[key] = self._render_dict(value, context)
            elif isinstance(value, list):
                result[key] = [self._render_dict(v, context) if isinstance(v, dict) else v for v in value]
            else:
                result[key] = value
        return result

5. 数据脱敏层 (Data Masking Layer)

5.1 敏感数据类型

| 类型 | 识别规则 | 脱敏策略 |
|------|---------|---------|
| 身份证号 | 18 位数字 | 保留前 3 后 4，中间替换 * |
| 手机号 | 11 位 1 开头 | 保留前 3 后 4 |
| 银行卡号 | 16-19 位数字 | 保留后 4 位 |
| 邮箱 | email 格式 | 用户名部分模糊 |
| 姓名 | 2-4 个中文字 | 保留姓，名替换 * |
| 地址 | 包含省市区 | 保留省市，详细地址模糊 |
| 密码 | password 字段 | 完全替换 |

5.2 脱敏器

class DataMasker:
    def __init__(self):
        self.rules = {
            'id_card': IDCardMaskRule(),
            'phone': PhoneMaskRule(),
            'bank_card': BankCardMaskRule(),
            'email': EmailMaskRule(),
            'name': NameMaskRule(),
            'address': AddressMaskRule(),
            'password': PasswordMaskRule()
        }
        self.detector = SensitiveDetector()
    
    def mask(self, data: dict, config: MaskConfig = None) -> dict:
        result = {}
        
        for key, value in data.items():
            if isinstance(value, dict):
                result[key] = self.mask(value, config)
            elif isinstance(value, list):
                result[key] = [self.mask(v, config) if isinstance(v, dict) else self._mask_value(key, v) for v in value]
            else:
                result[key] = self._mask_value(key, value)
        
        return result
    
    def _mask_value(self, field_name: str, value: any) -> any:
        if value is None:
            return None
        
        # 检测敏感类型
        sensitive_type = self.detector.detect(field_name, value)
        
        if sensitive_type and sensitive_type in self.rules:
            return self.rules[sensitive_type].mask(value)
        
        return value

class IDCardMaskRule:
    def mask(self, value: str) -> str:
        if len(value) == 18:
            return value[:3] + '*' * 11 + value[-4:]
        return value

class PhoneMaskRule:
    def mask(self, value: str) -> str:
        if len(value) == 11:
            return value[:3] + '****' + value[-4:]
        return value

5.3 敏感检测器

class SensitiveDetector:
    def __init__(self):
        self.patterns = {
            'id_card': r'^\d{17}[\dXx]$',
            'phone': r'^1[3-9]\d{9}$',
            'bank_card': r'^\d{16,19}$',
            'email': r'^[\w\.-]+@[\w\.-]+\.\w+$'
        }
        self.field_hints = {
            'id_card': ['id_card', 'idcard', 'sfz', 'identity'],
            'phone': ['phone', 'mobile', 'tel', 'telephone'],
            'email': ['email', 'mail'],
            'password': ['password', 'pwd', 'pass', 'secret'],
            'name': ['name', 'realname', 'real_name', 'username'],
            'address': ['address', 'addr', 'location']
        }
    
    def detect(self, field_name: str, value: any) -> str:
        # 1. 基于字段名提示
        field_lower = field_name.lower()
        for sensitive_type, hints in self.field_hints.items():
            if any(hint in field_lower for hint in hints):
                return sensitive_type
        
        # 2. 基于正则匹配
        if isinstance(value, str):
            for sensitive_type, pattern in self.patterns.items():
                if re.match(pattern, value):
                    return sensitive_type
        
        return None

class DataPool:
    def __init__(self, storage: PoolStorage):
        self.storage = storage
        self.pre_generated = {}
        self.temporary = {}
        self.shared = {}
    
    async def acquire(self, pool_name: str, data_type: str, 
                      count: int = 1, reusable: bool = False) -> list[dict]:
        """从数据池获取数据"""
        pool = self._get_pool(pool_name)
        
        if data_type not in pool or len(pool[data_type]) < count:
            # 池中数据不足，生成新数据
            await self._refill(pool_name, data_type, count * 2)
        
        # 获取数据
        if reusable:
            return pool[data_type][:count]
        else:
            # 非可复用，取出后从池中移除
            data = pool[data_type][:count]
            pool[data_type] = pool[data_type][count:]
            return data
    
    async def release(self, pool_name: str, data: list[dict]):
        """归还数据到池中"""
        pool = self._get_pool(pool_name)
        data_type = data[0].get('_type', 'default')
        pool.setdefault(data_type, []).extend(data)
    
    async def cleanup(self, pool_name: str, 
                      retention_hours: int = 24):
        """清理过期数据"""
        pool = self._get_pool(pool_name)
        cutoff = datetime.now() - timedelta(hours=retention_hours)
        
        for data_type in pool:
            pool[data_type] = [
                d for d in pool[data_type] 
                if d.get('_created_at', datetime.now()) > cutoff
            ]

7. 数据驱动测试 (Data-Driven Testing)

7.1 参数化支持

class DataDrivenRunner:
    def __init__(self, data_factory: DataFactory):
        self.factory = data_factory
    
    async def run_parameterized(self, tc_ir: TCIR, 
                                 data_source: DataSource) -> list[TestResult]:
        results = []
        
        # 获取测试数据
        test_data = await self._load_data(data_source)
        
        for index, data_row in enumerate(test_data):
            # 注入数据到 TC-IR
            parameterized_tc = self._inject_data(tc_ir, data_row)
            parameterized_tc.name = f"{tc_ir.name} [{index + 1}]"
            
            # 执行测试
            result = await self.executor.execute(parameterized_tc)
            result.data_row = data_row
            results.append(result)
        
        return results
    
    def _inject_data(self, tc_ir: TCIR, data: dict) -> TCIR:
        """将数据注入到测试用例"""
        tc_copy = tc_ir.copy()
        
        for step in tc_copy.steps:
            if step.value:
                step.value = self._replace_variables(step.value, data)
            if step.expected:
                step.expected = self._replace_variables(step.expected, data)
        
        return tc_copy
    
    def _replace_variables(self, text: str, data: dict) -> str:
        pattern = r'\$\{data\.(\w+)\}'
        def replacer(match):
            key = match.group(1)
            return str(data.get(key, match.group(0)))
        return re.sub(pattern, replacer, text)

POST /api/v1/data-factory/mask
{
  "data": [
    {"name": "张三", "phone": "13812345678", "id_card": "110101199001011234"}
  ],
  "rules": {
    "phone": "partial",  // full, partial, hash
    "id_card": "partial"
  }
}

响应：
{
  "masked_data": [
    {"name": "张*", "phone": "138****5678", "id_card": "110***********1234"}
  ]
}

10. 配置说明

data_factory:
  # 生成配置
  generator:
    default_locale: "zh_CN"
    batch_size: 100
    ai_model: "qwen-long"
  
  # 模板配置
  templates:
    path: "templates/"
    cache_enabled: true
  
  # 脱敏配置
  masking:
    default_strategy: "partial"
    detect_auto: true
    custom_rules:
      - field: "custom_id"
        pattern: "^[A-Z]{2}\\d{8}$"
        strategy: "partial"
        keep_first: 2
        keep_last: 2
  
  # 数据池配置
  pool:
    storage: "redis"  # redis, memory, database
    redis_url: "redis://localhost:6379/1"
    warm_up_on_start: true
    warm_up_schemas:
      - name: "user_schema"
        count: 1000
      - name: "order_schema"
        count: 500
