1. 系统概述 (System Overview)

1.1 定义与愿景

涡轮引擎 (Turbo Engine) 是重明架构中负责 "压" (Stress) 和 "量" (Measure) 的核心组件。它承载了重明鸟"负重"的神力，能够将 API-IR 资产快速转化为大规模并发压测脚本。

其核心设计哲学是 "Asset-Driven, Data-Amplified" (资产驱动，数据膨胀)：
- 资产复用：基于左瞳引擎积累的 API-IR 资产，无需重新编写压测脚本
- 数据膨胀：利用 LLM 智能生成海量符合 Schema 的测试数据
- 极速施压：通过 Locust 分布式架构实现高并发压测

1.2 核心职责
- 数据合成 (Data Synthesis)：基于 API-IR 定义，批量生成符合 Schema 的测试数据
- 脚本生成 (Script Generation)：将 API-IR 自动转译为 Locust 压测脚本
- 压测执行 (Load Execution)：配置并运行分布式压测
- 性能分析 (Performance Analysis)：收集并分析 TPS、响应时间、错误率等指标

3. 数据合成器 (Data Synthesizer)

3.1 设计目标

解决压力测试中"数据不够用"的痛点：
- 传统方式：手动准备测试数据，耗时且数量有限
- 涡轮方式：AI 基于 Schema 自动生成海量符合业务规则的数据

3.2 合成流程

=== Step 1: Schema 分析 ===

从 API-IR 中提取数据定义：

API-IR 输入示例：
{
  "method": "POST",
  "url": "/api/v1/orders",
  "body": {
    "buyer_id": "${user_uid}",
    "items": [
      {
        "product_id": "string",
        "quantity": "integer(1-10)"
      }
    ],
    "address_id": "integer"
  }
}

Schema 分析输出：
{
  "fields": [
    {"name": "buyer_id", "type": "uuid", "source": "variable"},
    {"name": "product_id", "type": "string", "pattern": "PROD_[0-9]{4}"},
    {"name": "quantity", "type": "integer", "min": 1, "max": 10},
    {"name": "address_id", "type": "integer", "range": [100, 999]}
  ]
}

=== Step 2: LLM 数据生成 ===

使用低成本模型批量生成符合 Schema 的数据：

class DataSynthesizer:
    def synthesize(self, schema: dict, count: int) -> list[dict]:
        prompt = f"""
        请根据以下 Schema 生成 {count} 条测试数据：
        {json.dumps(schema, ensure_ascii=False)}
        
        要求：
        1. 数据符合字段类型和范围约束
        2. 数据分布均匀，覆盖边界值
        3. 字符串字段生成有意义的中文/英文内容
        4. 输出 JSON 数组格式
        """
        return self.llm.generate(prompt, model="qwen-long")  # 使用低成本模型

=== Step 3: 数据存储 ===

生成的数据存储为 CSV/JSON，供 Locust 读取：

生成结果示例 (test_data_orders.csv)：
buyer_id,product_id,quantity,address_id
USR_001,PROD_1234,3,501
USR_002,PROD_5678,1,502
USR_003,PROD_9012,10,503
...

3.3 智能数据策略

| 策略 | 描述 | 适用场景 |
|------|------|---------|
| 均匀分布 | 字段值均匀覆盖范围 | 常规压测 |
| 边界覆盖 | 重点生成边界值 | 边界压力测试 |
| 热点数据 | 80% 集中在少量值 | 模拟真实流量分布 |
| 异常注入 | 混入非法值 | 异常容错测试 |

配置示例：
{
  "strategy": "hotspot",
  "hotspot_ratio": 0.8,
  "hotspot_values": ["PROD_0001", "PROD_0002", "PROD_0003"]
}

4. Locust 脚本生成器 (Script Generator)

4.1 设计目标

将 API-IR 资产"一键"转化为可执行的 Locust 压测脚本：
- 无需手写 Python 代码
- 自动处理依赖关系（如先登录获取 Token）
- 支持自定义权重和思考时间

4.2 编译流程

=== Step 1: API-IR 解析 ===

读取 API-IR 资产链：

[

  {"id": "STEP_02", "method": "POST", "url": "/orders", "dependencies": ["STEP_01"]}
]

=== Step 2: Jinja2 模板渲染 ===

使用模板生成 Locust 脚本：

class LoadRunner:
    def run(self, config: LoadConfig):
        # 1. 准备压测脚本
        locustfile = self.compiler.compile(config.api_ir)
        
        # 2. 准备测试数据
        test_data = self.synthesizer.synthesize(config.schema, config.data_count)
        
        # 3. 启动 Locust
        if config.mode == "local":
            cmd = f"locust -f {locustfile} --host {config.target_host}"
        else:
            cmd = f"locust -f {locustfile} --master --expect-workers {config.worker_count}"
        
        subprocess.run(cmd, shell=True)

8. LLM 选型配置

涡轮引擎的数据合成模块需要大量 Token 消耗，选择低成本模型：

| 子模块 | 推荐模型 | 理由 |
|-------|---------|------|
| Data Synthesizer | Qwen-Long / DeepSeek-V3 | Token 消耗大，关注成本 |
| Script Generator | 无需 LLM | 基于模板编译，无 AI 调用 |

配置示例：
{

    "synthesizer": {
      "model": "qwen-long",
      "temperature": 0.8,
      "max_tokens": 8192,
      "batch_size": 100  # 每次生成100条数据
    }
  }
}

10.1 设计目标

=== 引擎选择策略 ===

| 场景 | 推荐引擎 | 理由 |
|------|---------|------|
| 快速本地压测 | k6 | 单二进制、无依赖、启动快 |

=== API-IR 到 k6 脚本的转换 ===

class K6Compiler:
    """将 API-IR 转换为 k6 JavaScript 脚本"""
    
    def compile(self, api_ir_chain: list[ApiIR], config: K6Config) -> str:
        """编译 API-IR 为 k6 脚本"""
        template = self._get_template()
        
        return template.render(
            options=self._build_options(config),
            setup_code=self._build_setup(api_ir_chain),
            scenarios=self._build_scenarios(api_ir_chain),
            checks=self._build_checks(api_ir_chain)
        )
    
    def _build_options(self, config: K6Config) -> dict:
        return {
            "vus": config.virtual_users,
            "duration": config.duration,
            "stages": config.stages,
            "thresholds": {
                "http_req_duration": ["p(95)<1000"],
                "http_req_failed": ["rate<0.01"]
            }
        }

import { check, sleep } from 'k6';
import { SharedArray } from 'k6/data';

// 配置选项

    { duration: '30s', target: 100 },   // 爬升到 100 用户
    { duration: '5m', target: 100 },    // 稳定 5 分钟
    { duration: '30s', target: 0 },     // 降到 0

// 加载测试数据

  return JSON.parse(open('./test_data.json'));
});

  const loginRes = http.post(`${__ENV.BASE_URL}/api/v1/login`, JSON.stringify({
    username: 'loadtest_user',
    password: 'Test123!'
  }), { headers: { 'Content-Type': 'application/json' } });
  
  return { token: loginRes.json('data.token') };
}

// 主测试逻辑
export default function (data) {
  const headers = {
    'Authorization': `Bearer ${data.token}`,
    'Content-Type': 'application/json'
  };
  
  // 获取下一条测试数据

  // 创建订单

    { headers, tags: { name: 'ListOrders' } }
  );

  });

}

=== 弹性伸缩 HPA ===

class K6OperatorRunner:
    """基于 k6-operator 的 Kubernetes 压测执行器"""
    
    async def run(self, config: K6Config) -> K6TestRun:
        # 1. 创建 ConfigMap 存储脚本
        await self._create_script_configmap(config.script)
        
        # 2. 创建 K6 CRD 资源
        k6_resource = self._build_k6_resource(config)
        await self.k8s_client.create_namespaced_custom_object(
            group="k6.io",
            version="v1alpha1",
            plural="k6s",
            namespace=config.namespace,
            body=k6_resource
        )
        
        # 3. 监控压测进度
        return await self._watch_test_progress(config.test_id)
    
    def _build_k6_resource(self, config: K6Config) -> dict:
        parallelism = self._calculate_parallelism(config.vus)
        
        return {
            "apiVersion": "k6.io/v1alpha1",
            "kind": "K6",
            "metadata": {"name": config.test_id},
            "spec": {
                "parallelism": parallelism,
                "script": {
                    "configMap": {
                        "name": f"{config.test_id}-script",
                        "file": "test.js"
                    }
                },
                "arguments": f"--out influxdb={config.influxdb_url}/k6",
                "runner": {
                    "resources": {
                        "limits": {"cpu": "1", "memory": "1Gi"}
                    }
                }
            }
        }
    
    def _calculate_parallelism(self, vus: int) -> int:
        """计算需要的 Pod 数量，每 Pod 承载 ~250 VU"""
        return max(1, (vus + 249) // 250)

class GrafanaCloudK6Runner:
    """Grafana Cloud k6 托管压测"""
    
    def __init__(self, api_token: str, project_id: str):
        self.api_token = api_token
        self.project_id = project_id
        self.base_url = "https://api.k6.io/v3"
    
    async def run_cloud(self, script: str, config: CloudK6Config) -> CloudTestRun:
        """上传脚本到 Grafana Cloud 执行"""
        
        # 创建测试
        response = await self.client.post(
            f"{self.base_url}/projects/{self.project_id}/tests",
            headers={"Authorization": f"Token {self.api_token}"},
            json={
                "name": config.test_name,
                "script": script,
                "vus": config.vus,
                "duration": config.duration,
                "zones": config.load_zones  # ["amazon:us-east-1", "amazon:eu-west-1"]
            }
        )
        
        test_id = response.json()["id"]
        
        # 启动测试
        await self.client.post(
            f"{self.base_url}/tests/{test_id}/start",
            headers={"Authorization": f"Token {self.api_token}"}
        )
        
        return CloudTestRun(
            test_id=test_id,
            dashboard_url=f"https://app.k6.io/runs/{test_id}"
        )

10.6 统一执行器接口

class UnifiedLoadRunner:
    """统一压测执行器，支持多引擎切换"""
    
    def __init__(self, config: TurboConfig):
        self.runners = {
            "locust": LocustRunner(config.locust),
            "k6": K6LocalRunner(config.k6),
            "k6_operator": K6OperatorRunner(config.k6_operator),
            "k6_cloud": GrafanaCloudK6Runner(config.k6_cloud),
            "pts": AliyunPTSRunner(config.pts)
        }
        self.default_runner = config.default_runner
    
    async def run(self, api_ir_chain: list[ApiIR], config: LoadConfig) -> LoadTestRun:
        """根据配置选择引擎执行压测"""
        runner_name = config.runner or self.default_runner
        runner = self.runners.get(runner_name)
        
        if not runner:
            raise ValueError(f"Unknown runner: {runner_name}")
        
        # 编译脚本
        if runner_name.startswith("k6"):
            script = self.k6_compiler.compile(api_ir_chain, config)
        else:
            script = self.locust_compiler.compile(api_ir_chain, config)
        
        # 执行压测
        return await runner.run(script, config)
