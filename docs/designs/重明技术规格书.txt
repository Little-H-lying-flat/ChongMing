1. 项目概述
═══════════════════════════════════════════════════════════════════════════════

1.1 愿景

重明是一个 AI Agent 驱动的自动化质量工程平台，实现:
- PRD 驱动: 从需求文档直接生成测试用例
- 视觉主导: 像人一样"看屏幕"测试，抗前端变动
- API 智能: 自动理解 Swagger 文档，推理调用链
- 自愈能力: 失败时 AI 自动修复，热更新脚本

4.1 TC-IR (Test Case Intermediate Representation)

{
  "protocol": "TC-IR",
  "version": "1.0",
  "id": "TC_LOGIN_001",
  "name": "用户登录验证",
  "mode": "UI | API | HYBRID",
  "priority": "P0 | P1 | P2",
  "steps": [
    {"action": "navigate", "target": "${urls.web}/login"},
    {"action": "input", "target": "#username", "value": "${credentials.user}"},
    {"action": "click", "target": "登录按钮"}
  ],
  "assertions": [
    {"type": "url_contains", "expected": "/dashboard"}
  ]
}

4.2 API-IR (API Intermediate Representation)

{
  "protocol": "API-IR",
  "version": "1.0",
  "id": "API_USER_CREATE",
  "name": "创建用户",
  "request": {
    "method": "POST",
    "url": "/api/users",
    "headers": {"Authorization": "Bearer ${token}"},
    "body": {"username": "${username}", "email": "${email}"}
  },
  "extraction": {
    "user_id": "$.data.id"
  },
  "assertion": {
    "status_code": 201,
    "json_path": {"$.data.username": "${username}"}
  }
}

4.3 AUI-IR (Atomic UI Intermediate Representation)

{
  "protocol": "AUI-IR",
  "version": "2.0",
  "id": "STEP_UI_003",
  "execution_plan": {
    "primary": {
      "strategy": "visual",
      "action": "click",
      "target": "som_id:3",
      "coordinates": [200, 360],
      "confidence": 0.95
    },
    "fallback": {
      "strategy": "dom",
      "selector": "[data-testid='submit-btn']"
    }
  }
