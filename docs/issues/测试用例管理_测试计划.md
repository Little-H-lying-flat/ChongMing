# 测试用例管理模块测试计划

## 1. 测试目标
- 固化 6 态生命周期与流转规则的目标契约。
- 验证 `/api/v1/test-cases` 的向后兼容能力。
- 在代码改造前建立测试门禁，避免行为漂移。

## 2. 测试范围
- 单元测试：状态集合、流转矩阵、序列化兼容。
- 集成测试：`GET/POST/PUT/DELETE /test-cases` 契约场景。
- 回归测试：前端既有调用模式兼容性。

## 3. 用例清单

### 3.1 单元测试（Contract）
- 生命周期状态集合完整性：目标 6 态定义冻结。
- 合法/非法流转验证：按矩阵覆盖。
- 兼容序列化验证：旧响应字段必须存在，新字段可缺省。
- 过滤契约验证：`tag/status/mode/priority` 组合语义冻结。

### 3.2 集成/API 契约测试
- `GET /test-cases`
  - 旧参数 `page/page_size/status/mode/tag` 兼容。
  - 新参数 `priority/keyword/updated_from/updated_to/owner` 契约定义（先可 xfail）。
- `POST /test-cases`
  - 旧 payload 可创建成功。
  - 新生命周期字段契约定义（先可 xfail）。
- `PUT /test-cases/{id}`
  - 旧更新方式兼容。
  - 状态流转限制契约定义（先可 xfail）。
- `DELETE /test-cases/{id}`
  - 基础删除行为可用。
  - “被执行引用禁止删除”软规则预留（先可 xfail）。

### 3.3 回归清单
- `frontend/src/services/apiAutoService.ts` 请求参数不变可用。
- `frontend/src/services/turboService.ts` 对 `mode=API` 列表读取可用。
- `frontend/src/app/design/page.tsx` 与 `frontend/src/app/executions/page.tsx` 基础流程不受影响。

- 风险：先红后绿阶段 CI 噪声上升。
  - 缓解：`test-cases-contract` job 先 `allow-failure`，截止日期 2026-03-11 后转强制。
- 风险：产品流程与状态机不一致。
  - 缓解：实现前必须完成状态机评审签字。
- 风险：旧客户端兼容被破坏。
  - 缓解：保留旧路径旧字段的强约束测试。

## 7. 本地执行章节（固定入口）

### 7.1 推荐执行环境
- 优先使用 Python 3.11/3.12（与 CI 兼容性最佳）。
- 当前仓库存在损坏的 `.venv-py312` 时，可新建本地替代环境（例如 `.venv-local`）。

### 7.2 可复现命令
在 `backend` 目录执行：

```powershell
# 1) 新建虚拟环境（示例：本地仅有 py3.14 时）
py -3.14 -m venv .venv-local

# 2) 安装最小测试依赖（用于本轮 contract 测试）
.\.venv-local\Scripts\python.exe -m pip install --upgrade pip
.\.venv-local\Scripts\python.exe -m pip install pytest pytest-asyncio fastapi uvicorn httpx sqlalchemy aiosqlite pydantic pydantic-settings python-dotenv loguru celery redis tenacity aiofiles pymupdf openai langchain langchain-openai langgraph mem0ai

# 3) 执行 contract 测试（临时覆盖 DEBUG，避免本地 .env 干扰）
$env:DEBUG='false'
.\.venv-local\Scripts\python.exe -m pytest tests/unit/test_test_case_lifecycle_contract.py tests/integration/test_test_cases_api_contract.py tests/integration/test_test_cases_backward_compat.py -v
```

### 7.3 结果解释规范
- `PASSED`：兼容行为已满足当前实现。
- `XFAIL`：前瞻契约（6态、扩展筛选等）已冻结，等待后续实现转绿。
- `FAILED/ERROR`：环境或依赖阻断，需先修复后再判定业务契约。
