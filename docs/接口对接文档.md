## 1. 接口概述

### 1.1 API 基础信息

| 项目 | 值 |
|------|-----|
| 基础 URL | `http://localhost:8000/api/v1` |
| 协议 | HTTPS (生产) |
| 认证方式 | Bearer Token (JWT) |
| 数据格式 | JSON |
| 字符编码 | UTF-8 |

### 1.2 通用请求头

```http
Authorization: Bearer <jwt_token>
Content-Type: application/json
Accept: application/json
X-Request-ID: <uuid>  # 可选，用于追踪
```

### 1.3 通用响应格式

#### 成功响应
```json
{
  "code": 0,
  "message": "success",
  "data": { ... }
}
```

#### 错误响应
```json
{
  "code": 40001,
  "message": "Validation error",
  "detail": "tc_id: 长度必须在 1-64 之间"
}
```

### 1.4 错误码定义

| 错误码 | HTTP 状态码 | 描述 |
|--------|-------------|------|
| 0 | 200 | 成功 |
| 40001 | 400 | 请求参数错误 |
| 40101 | 401 | 未认证 |
| 40301 | 403 | 无权限 |
| 40401 | 404 | 资源不存在 |
| 42901 | 429 | 请求频率过高 |
| 50001 | 500 | 服务器内部错误 |

## 4. 测试执行接口

### 4.1 创建执行任务

```http
POST /executions
```

**请求体**
```json
{
  "tc_ids": ["tc-001", "tc-002"],
  "environment": "test",
  "parallel": 2,
  "config": {
    "browser": "chromium",
    "headless": true,
    "timeout": 30000,
    "enable_healing": true
  }
}
```

**响应**
```json
{
  "execution_id": "exec-xyz789",
  "status": "pending",
  "created_at": "2026-02-06T12:00:00Z"
}
```

### 4.2 获取执行状态

```http
GET /executions/{execution_id}
```

**响应**
```json
{
  "execution_id": "exec-xyz789",
  "status": "running",
  "progress": 0.5,
  "total_cases": 10,
  "passed": 4,
  "failed": 1,
  "results": [
    {
      "tc_id": "tc-001",
      "status": "passed",
      "duration": 1234,
      "screenshots": ["/screenshots/tc-001-step1.png"]
    }
  ]
}
```

### 4.3 SSE 进度流

```http
GET /executions/{execution_id}/stream
Accept: text/event-stream
```

**事件格式**
```
event: progress
data: {"progress": 0.3, "current_step": "执行 tc-002"}

event: result
data: {"tc_id": "tc-001", "status": "passed"}

event: complete
data: {"status": "completed", "passed": 8, "failed": 2}
```

**JavaScript 客户端示例**
```javascript
const eventSource = new EventSource('/api/v1/executions/exec-xyz789/stream');

eventSource.addEventListener('progress', (e) => {
  const data = JSON.parse(e.data);
  console.log(`进度: ${data.progress * 100}%`);
});

eventSource.addEventListener('result', (e) => {
  const data = JSON.parse(e.data);
  console.log(`${data.tc_id}: ${data.status}`);
});

eventSource.addEventListener('complete', (e) => {
  console.log('执行完成');
  eventSource.close();
});
```

## 13. Python SDK 示例

```python
from chongming import ChongMingClient

# 初始化客户端
client = ChongMingClient(
    base_url="http://localhost:8000",
    api_key="your_api_key"
)

# 解析 PRD
prd_result = await client.design.parse_prd(
    content="# 登录功能...",
    format="markdown"
)

# 生成用例
tc_list = await client.design.generate(
    prd_id=prd_result.prd_id,
    coverage_strategy="smoke"
)

# 执行测试
execution = await client.executions.create(
    tc_ids=[tc.id for tc in tc_list],
    environment="test"
)

# 订阅进度
async for event in client.executions.stream(execution.execution_id):
    print(f"进度: {event.progress * 100}%")
```

## 14. TypeScript SDK 示例

```typescript
import { ChongMingClient } from '@chongming/sdk';

const client = new ChongMingClient({
  baseUrl: 'http://localhost:8000',
  apiKey: 'your_api_key'
});

// 解析 PRD
const prdResult = await client.design.parsePrd({
  content: '# 登录功能...',
  format: 'markdown'
});

// 生成用例
const tcList = await client.design.generate({
  prdId: prdResult.prdId,
  coverageStrategy: 'smoke'
});

// 执行测试
const execution = await client.executions.create({
  tcIds: tcList.map(tc => tc.id),
  environment: 'test'
});

// 订阅 SSE 进度
const eventSource = client.executions.stream(execution.executionId);
eventSource.onProgress((data) => {
  console.log(`进度: ${data.progress * 100}%`);
});
```

### 16.3 签名验证

```python
import hmac
import hashlib

def verify_signature(payload: bytes, signature: str, secret: str) -> bool:
    expected = hmac.new(
        secret.encode(),
        payload,
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(f"sha256={expected}", signature)
```
